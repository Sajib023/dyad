Your own AI app builder,
on your own machine.

Describe an app in plain language. Dyad turns it into working code and runs a live preview — all on your hardware, with your API keys, under your control.

Local-first

Runs as a single Docker container on your NAS, laptop, or small VM. No cloud account, no per-seat pricing, no telemetry you can’t turn off.

⚿

Bring your own keys

Use Anthropic, OpenAI, Google, OpenRouter, or any OpenAI-compatible provider. Your keys never leave the container.

↗

Deploy anywhere

Generate production-ready code, then ship to Cloudflare, Coolify, Vercel, or your own server — straight from the chat.

Get started in one command

  1. docker compose up -d --build
  2. Open http://localhost:3000 in your browser.
  3. (Optional) Set DYAD_WEB_TOKEN=$(openssl rand -hex 24) in docker-compose.yml to password-protect your instance.
  4. Type an app idea into the prompt and press send. Dyad builds it.
